# Flexible Online Banking Web Application UI

## Overview
This exercise was undertaken to put my styling skills to the test to design a visually appealing home page which a user would see after logging into their bank account with this fictional company.<br>
Care and attention was taken to ensure that the page would look good and be readable and functional on any screen size that the user uses. Try and re-size the page and see.<br>
A preview of what this project looks like when deployed can be viewed on Vercel at this link: https://online-banking-web-upplication-ui.vercel.app/

## Tech Stack
- CSS3
- HTML5
